# Lulu 隐私说明

生效日期：2026-08-10

Lulu 是一款开源、以本地存储为默认方式的 Android AI 陪伴应用。本说明适用于本仓库发布的官方构建。

## 数据存储

- 角色卡、聊天、记忆、日记、待办、番茄钟记录、游戏记录和应用设置默认保存在设备本地。
- Lulu 不内置项目方可读取用户数据的账号系统，也不默认启用云同步。
- 用户可以主动配置 WebDAV、Supabase、模型供应商、搜索、语音或其他第三方服务。启用后，相关数据会按用户选择发送给对应服务，受该服务的隐私政策约束。
- API Key 由用户自行填写并保存在应用私有数据中。公开构建不包含共享 API Key。

## 模型请求

当用户发起聊天、记忆提炼、语音、图片生成或其他 AI 功能时，完成请求所需的文本、附件和上下文会发送给用户选择的模型供应商。Lulu 不会替用户自动选择或启用付费服务。

## 可选权限

Lulu 只在用户使用对应功能时申请或引导开启权限：

- 通知：主动消息、来电、番茄钟及后台任务提醒。
- 麦克风：语音输入和通话。
- 相机：用户主动拍照或授权角色使用相机工具。
- 位置：天气、附近搜索或用户主动配置的数据同步。
- 短信、日历：用户主动启用的本地工具。
- 通知读取、应用使用情况、应用列表：用户主动启用的设备感知功能。
- 文件：导入、导出和管理用户选择的文件。

拒绝非必要权限不会影响基础聊天。高敏感权限默认不自动授予，用户可随时在 Android 系统设置中撤销。

## 分析与崩溃上报

官方公开构建不集成 Firebase Analytics、Firebase Crashlytics 或项目方远程配置，不向项目方发送使用统计和崩溃报告。

## 删除与导出

- 用户可在“设置 → 数据”中备份或导出数据。
- 用户可在“设置 → 隐私与数据”中清除全部应用数据。该操作会删除本机 Lulu 的数据库、角色、聊天、文件、密钥和设置，且不可恢复。
- 卸载应用也会删除应用私有数据；用户主动导出到外部位置的文件需自行删除。
