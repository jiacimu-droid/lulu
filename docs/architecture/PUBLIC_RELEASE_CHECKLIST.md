# Lulu 公开版改造清单

> 目标：把私人使用版整理成可供任何用户首次安装、创建自己的角色并安全使用的公开版本。
> 原则：不预设用户身份、考试目标、关系、角色名、性别或亲密程度；必要的安全、权限和危险操作说明保留。

## P0：隐私与安全

- [x] 删除 `study-plans/kaoyan-2026/` 与 `docs/study-plan/learner-profile.md`。
- [x] 删除 `money-lab/`、`build_compile_output.txt`、`nul)` 等非产品资料或误提交文件。
- [x] 删除 `.claude/settings.local.json` 并加入忽略规则。
- [x] 清空 `remote_config_defaults.xml` 中的 SiliconCloud 密钥；旧值仍须在服务端轮换。
- [ ] 将真实 Firebase 配置改为构建环境注入，并提供不含凭据的示例。
- [x] 清理生产代码和测试中的“佳辞”“木佳辞”等真实姓名与个人特判。
- [ ] 清理本机路径、账号、私人赞助文案和不属于本项目的赞赏码。
- [ ] 对 Git 历史中的私人资料与密钥另行执行历史重写；密钥轮换不依赖历史重写。

## P1：首次使用与角色中立

- [x] 新安装不创建名为“露露”的默认角色；角色列表初始为空。
- [x] 没有角色时显示创建引导，学习番茄钟可纯计时，角色页面不使用固定角色兜底。
- [ ] 删除固定男性、恋人、温柔、宠溺、主人、考研等默认倾向。
- [ ] 所有聊天、电话、群聊、主动消息、游戏、日记、阅读和小剧场遵循用户创建的角色卡与关系边界。
- [x] 删除生产代码中针对固定用户姓名的过滤逻辑。

## P2：学习 App 精简

- [x] 桌面名称由“考研”改为“学习”。
- [x] 删除陪伴页及“某某陪你备考”、签到、作息奖励、夸夸值展示。
- [x] 今日页只保留番茄钟入口和用户自行添加的今日待办。
- [x] 删除预置学习文件、个人考研进度、今日计划、明日待办、Tips 和计划页。
- [x] 删除抽卡、收藏、成就、商店、说明页面及其路由和不可再达的实现代码。
- [x] 删除夸夸值、抽卡券、碎片、奖励、兑换、补偿、商店和成就业务链路。
- [x] 番茄钟预设时长改为 25、40、60 分钟；删除 50、90 分钟。
- [x] 番茄钟页面提供角色选择；没有角色时允许纯计时，但不生成角色陪学内容。
- [x] 保留番茄钟真实时长统计，让被选择的角色可读取真实学习记录。
- [x] 待办只保存用户手动输入的任务，不再自动同步私人计划。

## P3：心愿馆与阅读

- [x] 心愿馆删除画卷和视频模块、路由、数据模型、生成入口及碎片解锁逻辑。
- [x] 心愿馆只保留小剧场，所有小剧场默认可进入、无需碎片解锁。
- [x] 用户可自行添加、编辑、删除小剧场并生成章节。
- [x] 删除内置的“露露恋爱/男性/考研”画卷提示词和私人小剧场种子；公开版使用空书架。
- [x] 阅读 App 不再与“小剧场”同义：改为上传和管理用户文档，并支持选择角色共同阅读。
- [x] 删除“阅读小剧场”“女主角是我”“还没有可阅读的小剧场”等身份预设和解释性文案。
- [x] 角色只有在文档以真实附件进入对话后才能基于内容回复。

## P4：辞海、记忆与时间线

- [x] 辞海顶部提供紧凑的角色选择，所有内容严格按角色隔离。
- [x] 删除重复标题、角色说明卡、空状态长篇解释和内部机制说明。
- [ ] 保留必要的删除确认、状态含义和错误说明。
- [ ] 记忆库增加按角色查看的原始时间线，展示真实聊天、电话、游戏、阅读、日记与工具动作。
- [x] 原始聊天时间线与长期提炼记忆分层展示，并可回查原对话。
- [ ] 群聊事件为在场角色分别留档，并保留真实说话人和频道。
- [ ] 继续沿用连续批次、失败重试、日总结去重和来源回查能力。

## P5：电话、群聊与角色动作

- [x] 电话页移除头像和名字外层的装饰框，保持拨号、振铃、接通、通话、挂断状态清晰。
- [ ] 电话页重新检查间距、字幕、按钮对比度和无角色状态。
- [ ] 前台聊天与后台主动感知共用同一套真实动作执行层。
- [ ] 角色可真实执行私聊、跨群发言、游戏邀请、朋友圈、日记、阅读和来电；失败不得伪装成成功台词。
- [ ] 群聊中的角色可根据上下文转入与用户的真实私聊并发送真实游戏邀请。
- [ ] 群聊、私聊、电话、游戏和主动消息使用统一人设、世界书、记忆和关系上下文。
- [ ] 回复任务离开页面或切到后台后继续执行，并防止重复落库。

## P6：游戏

- [x] 游戏中心只保留五子棋和快艇骰子。
- [x] 删除满分男、跑团、海龟汤、默契问答、信号追踪等页面、路由和不可再达实现。
- [x] 两个保留游戏均允许选择角色，并将真实局次、结果和棋盘/计分细节写入共同时间线。
- [x] 游戏邀请只允许引用仍存在的游戏 ID。

- [ ] 替换 OrangeChat/RikkaHub 的旧官网、下载、Discord、Patreon、赞助和推广链接。
- [ ] 保留 Apache 2.0、上游版权、NOTICE 和必要致谢，不删除来源归属。
- [x] 将赞助页改为“支持 Lulu 项目开发”。
- [ ] 审查定位、短信、日历、通知读取、麦克风、摄像头、文件和应用列表权限，改为按功能申请。
- [ ] 增加正式隐私政策、数据存储说明、删除数据入口和第三方服务说明。
- [ ] 默认关闭云同步；API Key 由用户填写或安全后端代理，不打包公共密钥。
- [x] 清理无关构建产物、本地配置与调试日志。
- [ ] 更新代码索引，完成 Release Kotlin 编译、正式 APK 工作流和 Release 验收。

## 文案审查规则

- [ ] 删除重复标题、替用户设定身份的文字、已从界面明显可见的操作说明、内部实现解释和私人语气提示。
