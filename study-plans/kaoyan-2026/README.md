## 二、App 接入方式

考研 App 不在运行时解析 Markdown。App 使用结构化 Kotlin 计划：

`app/src/main/java/me/rerere/rikkahub/data/study/SelfDirectedStudyPlan.kt`

该文件是 `monthly-weekly-plan.md` 的运行时镜像，负责：

- App 中的月计划展示；
- App 中的当前周计划展示；
- 每日待办的短提醒模板；
- “生成短计划”时的模型提示；
- 不固定星期几休息、不自动生成满铺日程的新规则。

以后修改月计划或周计划时，必须在同一次改动中同步修改 Markdown 与 Kotlin；两者冲突时，不允许静默沿用旧 App 数据。

## 四、计划责任边界

- 助手负责月计划、周任务池、容量核算、阶段验收和遗漏检查。
- 本人负责把周任务分配到具体日期，决定哪一天休息和每天的先后顺序。
- 日常页面只提供少量短提醒；本人可删除、补充或重新排序。
- 未完成内容回到周任务池，不整套机械顺延，也不用熬夜惩罚式补课。
- 每周复盘后，用真实课程分钟、题量、背诵痕迹、英语完成量和有效学习时间更新下一周。
